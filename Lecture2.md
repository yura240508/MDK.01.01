# Введение в C++
## Язык програмирования C++
Язык програмирования C++ представляет высокоуровневый компилируемый язык програмирования общего назначения со статической типизацией своими корнями он уходит в язык C который был разработан в 1969-1973 годах компании Bell Labs програмистов Дэнисом Ритчи.
В начале 1980 годов датский прогрмасит Бьерн Страуструп который работал в компании Bell Labs разработал C++ как расширение к языку C. Фактически в начала C++ просто дополнял язык C, некоторыми возможностями ООП. Изначально язык назывался "Си с классами"
C++ является компилируемым языком, а это значит что компилятор траслирует исходный код на C++ в исполняемый файл, который содержит набор машинных инструкций.
### Основные компиляторы
- g++
- clang
- компилятор Microsoft VS
### Состав компилятора g++
- cpp - процессор
- as - ассемблер
- g++ - сам компилятор
- id - линкер
### Зачем нужно компилировать исходный файл
Исходный C++ файл это всего лишь код, но его невозможно запустить как программу поэтому каждый исходный файл требуется скомпилировать в исполняемый
### Этапы компиляции
- препроцесиинг - это макропроцессор который преобразовывает программу для дальнейшего компилирования на данной стадии происходит работа с препроцесовными дерективами. Например препроцесор добавляет хэдеоы в код (#include), убирает комментарии
- компиляция преобразвания в асемблерный код. Это промежуточный этап между высокоуравневым языком и машинным кодом
- ассмеблирование перевод асемблированного кода в машинный <br> объектный файл - это созданный асемблиром промежуточный файл хранящий кусок машинного кода этот кусок машинного кода который еще не был связан вместе с другими кусками машинного кода называется объектным кодом
- компановка (компновщик линкер) связывает все объектные файлы и статические библиотеки в единый исполняемый файл.
