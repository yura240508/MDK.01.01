## Основное

**Вектор** (`std::vector`) и **строка** (`std::string`) — базовые контейнеры стандартной библиотеки C++. Они хранят элементы в **непрерывном фрагменте памяти**, поддерживают доступ по индексу и эффективное добавление элементов в конец.

---

## 1. Контейнер `std::vector`

**Вектор** — динамический массив, который:

- быстро добавляет элементы в конец
- автоматически меняет свой размер
- гарантирует отсутствие утечек памяти

### Подключение и объявление

```cpp
#include <vector>

std::vector<int> data;              // вектор целых чисел
std::vector<std::string> words;     // вектор строк
```

> ⚠️ `std::vector` — это **шаблон**, а не тип. Тип элемента задаётся в угловых скобках и должен быть известен при компиляции.

### Способы инициализации

```cpp
std::vector<int> data = {1, 2, 3, 4, 5};        // список инициализации
std::vector<std::string> v1;                     // пустой вектор
std::vector<std::string> v2(5);                  // 5 пустых строк
std::vector<std::string> v3(5, "hello");         // 5 строк "hello"
```

### Пример: вывод через range-for

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};
    for (int elem : data) {
        std::cout << elem << " ";
    }
}
```

## 2. Обращение к элементам

Индексация начинается с нуля:

```cpp
std::vector<int> data = {1, 2, 3, 4, 5};
int a = data[0];      // 1
int b = data[4];      // 5
data[2] = -3;         // изменение элемента
std::cout << data.size();  // 5
```

> ❌ Отрицательные индексы **не допускаются**.

### Оператор `[]` vs функция `at`

| Способ | Проверка границ | Поведение при ошибке |
|--------|----------------|----------------------|
| `data[i]` | ❌ нет | неопределённое поведение |
| `data.at(i)` | ✅ есть | исключение `std::out_of_range` |

```cpp
data[42];      // неопределённое поведение
data.at(42);   // исключение
```

> 💡 Принцип C++: «мы не должны платить за то, что не используем». Проверки замедляют программу, поэтому `[]` их не делает.

### `front()` и `back()`

```cpp
data.front();  // == data[0]
data.back();   // == data[data.size() - 1]
```

> ⚠️ Вызов на пустом векторе — неопределённое поведение.

### Проверка на пустоту

```cpp
if (!data.empty()) { /* вектор не пуст */ }
```

Принято использовать `empty()`, а не `data.size() == 0`.

## 3. Итерация по индексам

Размеры и индексы имеют **беззнаковый тип** `size_t` (псевдоним `std::vector<T>::size_type`).

### Каноническая форма цикла

```cpp
for (size_t i = 0; i != data.size(); ++i) {
    std::cout << data[i] << " ";
}
```

Принято использовать `!=` и префиксный `++i`.

### ⚠️ Проблема беззнаковости

Выражение `data.size() - 1` при `size() == 0` даст **максимальное беззнаковое число** (не `-1`).

**Ошибочный код** (падает на пустом векторе):

```cpp
for (size_t i = 0; i < data.size() - 1; ++i) { /* ... */ }
```

**Исправления:**

```cpp
// Вариант 1
for (size_t i = 0; i + 1 < data.size(); ++i) { /* ... */ }

// Вариант 2 (C++20)
for (std::int64_t i = 0; i < std::ssize(data) - 1; ++i) { /* ... */ }
```

## 4. Добавление и удаление элементов

| Функция | Действие | Сложность |
|---------|----------|-----------|
| `push_back(x)` | добавить в конец | амортизированно O(1) |
| `pop_back()` | удалить с конца | O(1) |
| `clear()` | удалить все элементы | O(n) |

> ⚠️ Добавление/удаление из **середины или начала** неэффективно (нужен сдвиг элементов). Для этого есть `insert` / `erase` с итераторами.

### Пример: чтение чисел и удаление нулей в конце

```cpp
int x;
std::vector<int> data;
while (std::cin >> x) {
    data.push_back(x);
}

while (!data.empty() && data.back() == 0) {
    data.pop_back();
}
```

## 5. Резерв памяти

Вектор хранит элементы **непрерывно** и резервирует дополнительное место в конце.

- **Реаллокация** — копирование элементов в новый блок памяти при исчерпании резерва.
- При удвоении размера блока **амортизационная сложность** `push_back` — **O(1)**.

### `size()` vs `capacity()`

```cpp
std::vector<int> data = {1, 2};
data.push_back(3);  // size=3, capacity=4
data.push_back(4);  // size=4, capacity=4
data.push_back(5);  // size=5, capacity=8 (реаллокация)
```

### `reserve()` — резервирование памяти

```cpp
words.reserve(words_count);  // размер остаётся 0, меняется только capacity
```

> Если передать значение меньше текущего резерва — ничего не изменится.

### `resize()` — изменение количества элементов

```cpp
data.reserve(10);  // size=5, capacity=10
data.resize(3);    // удалены последние 2 элемента
data.resize(6);    // {1, 2, 3, 0, 0, 0}
```

| Функция | Что меняет |
|---------|-----------|
| `reserve(n)` | только `capacity` |
| `resize(n)` | `size` (и, при необходимости, `capacity`) |

## 6. Многомерные векторы (матрицы)

```cpp
size_t m, n;
std::cin >> m >> n;

// матрица m×n из нулей
std::vector<std::vector<int>> matrix(m, std::vector<int>(n));

for (size_t i = 0; i != m; ++i)
    for (size_t j = 0; j != n; ++j)
        std::cin >> matrix[i][j];
```

## 7. Сортировка вектора

```cpp
#include <algorithm>

std::sort(data.begin(), data.end());          // по возрастанию
std::sort(data.rbegin(), data.rend());        // по убыванию
```

- Сложность: **O(n log n)** в худшем случае (обычно Introsort).
- `begin()` / `end()` — итераторы диапазона.
- `rbegin()` / `rend()` — обратные итераторы.

### C++20: `std::ranges::sort`

```cpp
std::ranges::sort(data);  // передаём сам вектор
```

> Сравнение по умолчанию — оператор `<`. Векторы сравниваются **лексикографически**.

## 8. Строки `std::string`

`std::string` — это по сути `std::vector<char>` с дополнительными функциями. Наследует `pop_back`, `resize` и др.

### Специфические операции

**Приписывание:**

```cpp
s += ' ';           // аналог push_back
s += "functions";   // добавление строки
```

**Выделение подстроки:**

```cpp
s.substr(5, 6);  // 6 символов начиная с позиции 5
s.substr(12);    // с позиции 12 до конца
```

**Поиск:**

```cpp
s.find(' ');              // позиция первого пробела
s.find(' ', pos1 + 1);    // следующий пробел
s.find("str");            // поиск подстроки
s.find("#");              // std::string::npos, если не найдено
```

**Вставка, замена, удаление:**

```cpp
s.insert(5, "std::");       // вставка подстроки
s.replace(0, 4, "Special"); // замена диапазона
s.erase(8, 5);              // удаление подстроки
```

### C++20: `starts_with` / `ends_with`

```cpp
if (phrase.starts_with("hello")) { /* ... */ }
if (phrase.ends_with("bye"))     { /* ... */ }
```

---

## Ключевые выводы

1. `vector` и `string` — контейнеры с **непрерывной памятью** и доступом по индексу.
2. Оператор `[]` **не проверяет** границы; для безопасного доступа — `at()`.
3. Индексы и размеры **беззнаковые** (`size_t`) — осторожно с `size() - 1`.
4. `push_back` / `pop_back` — **эффективны только для конца**.
5. `reserve` меняет capacity, `resize` — size.
6. Для сортировки — `std::sort` или `std::ranges::sort` (C++20).
7. `string` = `vector<char>` + удобные методы (`substr`, `find`, `insert`, `replace`, `erase`).
